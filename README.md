# 🛠️ Support Hub

> 技术支持工程师的公开工作台：故障排查手册 · 诊断脚本 · 环境模板 · 最佳实践

## 📂 目录结构
support-hub/
├── docs/ 知识库文档（FAQ / 排查手册 / 搭建指南）
├── scripts/ 运维脚本（诊断 / 自动化 / 工具）
├── docker/ 容器化配置模板
└── templates/ 标准化模板（Issue / 报告 / 复盘）
## 🚀 快速使用

### 查看排查手册
进入 `docs/` 目录，按分类查找对应文档。

### 运行诊断脚本
bash
python scripts/diagnostics/health-check.py
### 启动测试环境
bash
cd docker/
docker-compose up -d
